# Preview console setup (pilot fixture)

## 1. Create the workspace
1. Open the preview console and click `Create workspace`.

## 2. Invite the reviewer
1. Open `Settings`.
2. Click `Members`.
3. Click `Invite member`.
4. Set `Role: Viewer`.
5. Click `Send invite`.

## 3. Rotate the key
1. Open `Settings`, then `Keys`, then click `Rotate`.
