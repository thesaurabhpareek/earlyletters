# Error registry (lessons the harness must not relearn)

Format: one row per error CLASS, not per incident. A class that has two incidents must have a detector (a gate, a test, an eval task or a rule) within one sprint, or the row says why not. Status: `detected` (a check fails on it today), `eval` (an eval task exists, no gate yet), `open` (only a human catches it). Evidence ids are PRs, commits or review files from 27 to 28 Oct 2026; V = checked by me, I = inferred.
