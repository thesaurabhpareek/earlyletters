## 5. AI limits (`ai-and-speech.md`)
The library and the media are a source of dates and files, never of words (`ai-and-speech.md:339` position line [E: line near 339]). Specific limits:
- Inputs to moments are only asset type, creation date and an in-memory asset id; no pixel, filename, caption, place, favourite or hidden flag (FR-AIS-57, `:342`); the moment function is pure and deterministic with an injected clock and zone (FR-AIS-58, `:343`); nothing describes what a picture shows or offers words, a title, a caption or a prompt from it (FR-AIS-59, `:344`); a red-team set in CI proves the output equals the rules-only, text-free result (FR-AIS-60, `:345`).
- Deny-list conflict: FR-AIS-54 fails builds on module names matching `suggest`, `classif`, `tone`, `improve` and others outside `packages/core/src/lang` and refusal tests; FR-AIS-61 says "no exemption" and wants the library module named for what it does, for example `photo-days` (`:346`). Card 21 and the handoff name `pickSuggestion()`, a `suggestion` start source, `EXPO_PUBLIC_SUGGESTIONS` and a `suggestions` module family (NS-49-R2, R31; `24:78`). FUNCTION-TRACE row for FR-AIS-54 is "needs Karma ruling" and no GAP-LOG ruling decides it (`FUNCTION-TRACE.md:546`). To Karma and product: one of the two must change before the NS-49 level 2 module is named.
- Video sound is never read, extracted, transcribed or analysed (FR-AIS-62, `:347`); a later founder ruling that opens it needs a separate field, never `raw_transcript`, with `verifyEdits` unchanged and a separate consent (FR-AIS-63, `:348`); adding, replacing or removing media or editing its words leaves `final_text`, `raw_transcript`, `machine_edits` and engine version byte-identical (FR-AIS-64, `:349`); Apple's people or face groupings are never read (FR-AIS-65, `:350`); text arriving with media (filename, album title, IPTC text) is data, never a suggestion, never sent to a model (FR-AIS-66, `:351`); media fixtures are generated and no media metadata goes to a hosted model (FR-AIS-67, `:352`); a picture's words field has writing tools off (FR-AIS-68, `:353`).
- Base limits this ties to: `EditType` union equals the seven names (FR-AIS-01), no machine edit bypasses `verifyEdits` (FR-AIS-02), ceiling on model edits at 15 percent of raw words for entries of 3 words or more (FR-AIS-03), no server transcription in v1.0 (FR-AIS-17), no hosted edit model until the gates in FR-AIS-19 hold (`ai-and-speech.md:136-164`).
