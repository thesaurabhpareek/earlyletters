# Next set of requirements (8 Nov 2026)

This folder is the output of the founder's "next set of requirements" programme. Docs only, drafts.
It changes no decision, sets no price and edits no other file.

- `00-stack-rank.md`: the ordered list of what to build next (tiers 0 to 3), checklists, critical path, founder decisions, what to measure.
- `01-customer-needs.md`: ranked customer needs and research gaps.
- `02-benchmark.md`: competitor and platform scan, read 8 Nov.
- `03-requirements/`: twelve themes with checks (Given, When, Then), gates and device rows. Start at `00-index.md`.
- `04-feasibility.md`: engineering sizes, architecture decisions AD-1 to AD-11, reliability debt.
- `05-compliance-risk.md`: engineering reading of legal and store rules, a risk register, stop and go ratings. Not legal advice.
- `06-roi.md`: scoring model, ranked table, unit economics sketch, measurements.
- `07-debate.md`: the council debate on eight disagreements, with tie-breaks and ways back.

Read `00-stack-rank.md` first, then `07-debate.md`. Every figure is from a cited file or marked ASSUMPTION.
No usage or revenue data exists. Dates are estimates from `docs/release/BUILD12-GAP-MAP-2026-11-08.md`.
The roles that speak are Claude roles, not people, and none is a lawyer.
Founder-only decisions are collected in section 5 of the stack rank.
