# CISO rulings on the items the wave 2 council could not play (1 Nov 2026)

The experience council (`proposals/v1-experience/council.md`) did not play the CISO and flagged: the Google skip-nonce setting (L11) and the email code length (D8), and a "CISO review" gate on the 1.1 sign-in prerequisites (release map). The threat model in this folder raised the rest. Codes continue from CISO-3 (account council) and are **provisional** until filed in `docs/agents/exec/RULINGS.md` or the Project doc `infra/exec-rulings-2026-11-01-*.md`, which this session cannot write.

Verdicts as Karma's skill defines them: RULED, FOUNDER, NOT A QUESTION, NEEDS EVIDENCE. Each rule says whether it relies on a **control** (a test or setting a machine checks) or a **policy** (a written rule).

Signed: CISO (Claude role, not an auditor). Not a penetration test; no attack was run against anything live. The only live read was public DNS through dns.google.
