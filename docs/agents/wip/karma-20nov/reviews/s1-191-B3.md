### S1-191 A book made without a name reads well on every screen a person sees (NX-31-R3, NX-36 S13 and S14; branch feat/mobile-nameless-surfaces)
- **Needs:** a build of this branch on an iPhone SE 3 (or the smallest phone to hand), fresh install, servers off is enough. Larger Text at AX5, VoiceOver and dark mode for the rows named below. Fictional family only: Asha, typed in step (g) and nowhere before it.
- **Steps:** (a) First run: leave the name empty, choose the same date two months back (for example 10 Jan if today is 10 Mar; not older: the name questions are only drawn for a baby under four months, so a seven-month-old book would pass step (e) without testing anything), finish. On Tonight, read the line above the greeting; with VoiceOver, swipe to it. (b) Tonight: Type, to open Write; read the line above the page; with VoiceOver, swipe to it. Close Write. (c) Settings, Children: read the row, then at AX5, then with VoiceOver. (d) Book tab: look at the cover, closed and open, in light and dark. (e) Tonight: press "Another thought" twenty times, then again twenty times on Write (on the two-month-old book from step (a)). (f) Settings, Children, the book, Name: look at the page as it opens, type a letter, delete it, type spaces only. (g) Type Asha, Save, then look at Tonight, Write and the Children row again. (h) In a second fresh install (delete the app and install the same build again on the same phone), leave the name empty and choose "expecting" with a due date; read Tonight and Write, then press "Another thought" twenty times on Tonight and twenty times on Write.
- **Expected:**
  - (a) The line is the age alone, "2 MONTHS" (capitals are the screen's own; the date in step (a) makes it exactly this): no dot before it, no "YOUR CHILD" and no blank where a name would be. VoiceOver reads the same words in lower case, not "dot 2 months".
  - (b) Write's line reads exactly as Tonight's did, with no leading dot and no "YOUR CHILD"; VoiceOver reads the same words.
  - (c) The row reads "Your child" with a capital Y, never blank and never lowercase; VoiceOver reads "Your child"; at AX5 the row wraps and nothing is cut off.
  - (d) The cover shows the mark and, on its foot line, "From" and the signature (for example Mama), no name line, no gap and no placeholder text, in both themes (this is the council's "cover with a blank name" row; record how it looks).
  - (e) None of the forty draws asks about the name: no prompt about how the name was chosen or where it came from (there are two name prompts, one for the first months and one for before the birth; today they read "Tell your child how the name was chosen." and "Where did the name your child come from? Who said it out loud first?", and #703 may reword them). Other prompts read normally, and "Another thought" never repeats the one on screen.
  - (f) The Name page opens with an empty field and no error line, and Save is dimmed. Typing a letter shows no error line; deleting it again shows none. Spaces only show "Add a name to save." and Save stays dimmed. (On a book that has a name, clearing the field does say "Add a name to save.")
  - (g) Save works. Tonight and Write now read "ASHA", a dot, then the age in capitals (VoiceOver "Asha, 2 months"); the Children row reads "Asha"; the name prompts may come back.
  - (h) Tonight reads "BEFORE YOU" (VoiceOver "Before You"), with no dot, no name and no blank. Write shows no line above the prompt (Write has never named a stage before the birth; a book with a name shows the name alone there), and no dot or empty gap where it would be. None of the forty draws (twenty on each screen) asks about the name (the before-birth set also holds name prompts).
- **Record:** S1-191 rows (a) to (h): phone, iOS version, build number and profile; screenshots of Tonight, Write, the Children row at AX5 and the cover in light and dark (rows (a) to (e) show no name; row (g) shows Asha only); the prompt texts seen in (e) (they never carry a child's name).
- **Update:** the name-absent audit table (NX-36 section 5) for any surface that reads differently on the phone, and the pins in `apps/mobile/test/nameless-surfaces.test.ts` if a rule changes.
