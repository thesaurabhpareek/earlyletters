## 3. Place-name dataset licences

Repo state, read 21 Nov 2026 in `docs/product/prd/28-moments-tab.md`: no place dataset is named. Option P-A is "a bundled table of cities, regions and countries" (line 407); PR 5b is the table package with a "licence note" (line 1026); the dataset licence row says "UNVERIFIED; prefer a source with a permissive, attribution-only licence" (line 1144); R229 wants "stable external ids from a public gazetteer" (line 1265); the gate is G11b. So the table below is a list of candidates people commonly use, not a choice, and not a recommendation. Counsel reads the full licence text before adoption (G11b).

US-only, so it would not cover a world table. |

Notes for the PR 5b author, engineering reading only:
- Attribution-only licences (3.1, 3.5, and 3.2 optionally) need a credit string and a place for it (Settings, About or Acknowledgements). Any text the app shows is `packages/content` copy and the public name stays in `packages/brand`. A credit that names the dataset must pass the content rules.
- ODbL candidates (3.3, 3.4) add a share-alike and notice duty whose reach over a bundled, app-shipped table is for counsel to read. The PRD already marks this as G11b.
- A dataset with a persistent public id (GeoNames ids) matches R229; Natural Earth and OSM extracts need a stable-id plan.
