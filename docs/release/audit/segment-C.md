## Headline finding
The server half of "life with the book" (invites, roles, approval, leave, last-parent guard, per-child sharing, delete/restore) is built and heavily tested in Postgres (supabase/migrations + supabase/tests). The phone half is local-only: `currentUserId()` returns null (apps/mobile/src/lib/store.ts:297), `hasPlus()` returns false (:302), `listMembers()` returns [] (:327), no supabase or PowerSync dependency in the mobile app (no match in apps/mobile/package.json; store.ts header says "Sync to Supabase comes later (PowerSync, ADR 0004)"). No client code calls any family RPC. Invite, approval, remove, leave, sync, export, backup, audio playback and Read-together highlight are therefore not reachable by a customer.
