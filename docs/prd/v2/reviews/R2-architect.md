# R2 Architect review of PRD V2

Reviewer: independent principal architect (did not write the PRD). Date: 13 Oct 2026. Scope: `README.md`, `_AUTHORING.md` 3b, `06-nfr.md`, `08-delivery.md`, `09-decisions-and-risks.md`, sections 7, 8, 9, 11 and 12 of F04, F05, F06, F08, F11, F14, F16, F17, F19, checked against `apps/mobile/src`, `apps/mobile/app.config.ts`, `packages/core`, `packages/api`, `supabase/migrations`, `supabase/functions` and `docs/adr` on the working tree read today. Line numbers are from those files as read on 13 Oct.

## Verdict

**Not ready to build the server half. The local half can keep going.**

The on-device parts (capture, edit engine, packs, StoreKit on the phone) are specified well and mostly match the code. The M14 server scope is not. Four things block the build:

1. F16 specifies a sync protocol that was never built. The built one differs in signatures, tables, removal model and, worst, conflict rule (last writer wins against a spec that says compare-and-set and "neither version lost").
2. The backup key model (one key per child) fails in the product's core case: a book with two parents.
3. The free-letter ledger counts the other parent's letters, so every co-parent who joins a book with letters in it is gated on their first own letter, permanently.
4. `book_access` is a P0 requirement and a hard dependency of F11, and `08-delivery.md` says it is not in v1.0.

Behind those sit P1 gaps that an agent would otherwise guess at: escrow security, escrow key custody, the status report's identity and staleness, deletion across the new systems, ownership overlaps between streams, and NFR gates that cannot pass as written (freshness p95 5 s, kill switch 5 minutes, crash-free 99.8% from a 16-day beta).

Fix the P0 rows (about two working days of spec and ADR work) before any wave 2 server PR. Fix the P1 rows before wave 2 starts on Mon 26 Oct. On this evidence I would put the 23 Nov submission below the 40% in `08-delivery.md` section 2.2, mainly because backup gets no beta exposure (AR-19) and the merge budget covers less than half the WPs (AR-20).
