Memory Library wireframes

Companion to MEMORY-LIBRARY-FLOWS-10nov.md (10 Nov 2026, draft). Static HTML and CSS, no scripts, no fonts, no images and no external requests. Colours are the real hex values from packages/design-tokens/src/tokens.ts, as used in the NX-36 wireframes. Photo tiles are tonal blocks, not pictures. Typefaces are stand-ins. Layout and hierarchy studies, not pixel specs. AX5 frames use an illustrative 2.4 scale. All copy is placeholder and needs founder word approval. Occasion names and dates are placeholders, not content.
