## 3. Cross-cutting patterns

- Moments is a very complete spec on a shell. The risk is not missing design; it is that the specs have already drifted from develop (CDO-B-016, 019, 020) before one line is built. A re-sync pass before the first Moments PR is cheaper than reviewing three PRs against stale text.
- Pictures live in four places (Home start, Moments, Book lens, capture Add) with no one-page statement of what each is for (CDO-B-012, 052). I would write that page before more spec.
- Several rules read stricter than the constitution needs ("no digit" on the picker, CDO-B-033). The constitution bans counting gaps and machine authorship; it does not ban a plain count of what exists. A VoiceOver parent pays for the stricter reading.
- Missing states pattern: the built tabs have no loading, error or offline states because they read the phone. Moments adds the first screen where that is not true (library read, iCloud arrival); only the specs cover it.
