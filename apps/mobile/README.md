# apps/mobile (`@scribe/mobile`)

The iOS-first Expo app (Expo SDK 57, Expo Router). Android comes later. The public product name, scheme and bundle ID come from `packages/brand`; do not type them here.

Read the repo root `CLAUDE.md` first: the constitution, content rules and privacy rules apply to every change in this folder.

## Run it

From the repo root, once:

```bash
nvm use                 # Node 22 (see .nvmrc); mobile tests need node:sqlite
npm ci
```

Then:

```bash
npm run mobile          # expo start for this workspace
npm test -w @scribe/mobile
npm run typecheck -w @scribe/mobile
```

`.env.development` sets `EXPO_PUBLIC_APP_ENV=development` for local `expo start` only. EAS builds set it per profile in `eas.json`. See `src/lib/build-env.ts`.

## Layout

| Path | What |
|---|---|
| `app.config.ts` | Expo config. Reads identity from `packages/brand` and the microphone string from `src/lib/permission-copy.ts` |
| `src/app` | Screens and routes (Expo Router, file-based) |
| `src/components` | UI components, grouped by feature |
| `src/lib` | Device-side logic: local database, capture, transcription, dates, copy. See `src/lib/README.md` |
| `modules/` | Local native modules (hand-written Swift lives in `modules/*/ios`) |
| `test/` | Vitest unit tests for the pure parts of `src/lib` (run in Node, no React Native) |
| `web-preview/` | Web-only Metro shims used by `metro.config.js` |
| `assets/` | Icons, licensed photos and sounds. `assets/expo.icon` and `assets/images/icon.png` are placeholders until the brand icon exists |

## Native folders

`ios/` and `android/` are generated by `expo prebuild` and are ignored by git. Do not commit them.
